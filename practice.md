# OmicTerms Practice Log

This is the index of practice work for skills we convert from "I watched it" to
"I can do it".

## How to use

- **Every new feature gets fresh practice files** under
  `practice/features/<feature>/` in this repo — its own drill, its own runnable
  files.
- You **run the drill on your own machine** and see it work before moving on.
- **Exception:** when a new feature builds directly on a previous feature's
  files, we reuse those files instead of starting fresh (no pointless copies).
- Each drill targets 5-10 minutes. If it needs longer, the drill is too big.
- When you're stuck, say so at the next review and we iterate — then move on.

## Drill template (one per feature)

```
## Drill — <feature>: <concept>

### Concept
<2-3 lines: the idea, in plain language>

### Files
<path(s) under practice/features/<feature>/ — run, poke, break, fix>

### Your drill
<one small hands-on task>

### Check
<what "correct" looks like — how you self-grade>

### Mastered when
<the one-line signal that you've got it>

---
```
